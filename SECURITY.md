# Security Policy

## Supported Versions
| Version | Supported |
| :--- | :--- |
| 1.0.x (Prototype) | :white_check_mark: |

## Reporting a Vulnerability
The AQUAFORGE development team takes maritime software security seriously. If you discover a vulnerability or security flaw:
1. Please do NOT open a public GitHub issue.
2. Email team lead / maintainers with the subject `[SECURITY] AQUAFORGE Vulnerability Report`.
3. Provide steps to reproduce, sample payloads, and suspected impact.
4. The team will acknowledge within 48 hours and provide a patch.

## Security Controls
- Uploaded files are subject to strict MIME and extension validation.
- Binaries are never executed.
- Decompression bombs and path traversals are actively mitigated.
